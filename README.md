# Setshaba Mashile Portfolio

Modern React + Vite personal developer portfolio.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Build

```bash
npm run build
```

## Before publishing

Update these placeholders in `src/main.jsx`:
- `your.email@example.com`
- LinkedIn URL

The GitHub and SecureRide URLs are already configured.

## Free hosting

### Vercel
1. Push this folder to GitHub.
2. Import the repository into Vercel.
3. Framework: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

### GitHub Pages
Use a GitHub Pages deployment action or a Pages-compatible Vite setup. Vercel is the simplest option for this project.
